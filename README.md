# Semester

Daily lectures, the weekly timetable and endsem countdowns in one app.

**Live:** https://unlockingprime.github.io/timetable/

- **Today:** lectures for the day, with free time between them
- **Week:** the full timetable grid
- **Exams:** date, time, venue and days left for each endsem
- Tap a lecture to see its marks and notes. Use **Back up** / **Restore** to save or load your data as a `.json` file.

## Install on Android

Open the link in Chrome and tap **Install** on the pop-up.

## Update

Change `COURSES`, `SCHED` or `EXAMS` in `index.html`, then bump `VERSION` in `sw.js`.
